# 讲解视频脚本

建议时长 6 分钟，采用 1080p 屏幕录制。录制前执行 `pnpm build && pnpm start`，使用独立演示数据库，确认 AI 状态和网络稳定。

## 00:00-00:25 开场

画面：登录页。

讲解：

> 这是知澜智慧校园，一个融合 AI 助教、课程、作业、考勤和学情分析的双角色智慧教育平台。下面从学生和教师两条真实业务链展示完整操作。

## 00:25-01:25 学生工作台与课程

操作：

1. 学生身份点击“一键填入”并登录。
2. 展示待完成作业、AI 建议、学习趋势、任务和校园公告。
3. 进入“我的课程”，选择《概率论与数理统计》。
4. 切换“考勤”标签，展示本人考勤状态。

讲解重点：

> 工作台数据来自当前学生数据库，而不是静态卡片。课程详情同时展示课程进度、任务、公告和本人出勤记录。

## 01:25-02:15 作业提交与反馈

操作：

1. 进入作业中心。
2. 打开一项待提交作业，填写作答并提交。
3. 展示提交状态、截止时间与教师反馈区域。

讲解重点：

> 截止前学生可以修改提交，评分后服务端会拒绝再次修改。教师批改后，学生端会收到通知并看到评分反馈。

## 02:15-03:00 AI 助教

操作：

1. 进入 AI 学习助理。
2. 选择课程上下文，点击“生成复习计划”。
3. 展示回答、模型来源、历史会话和删除操作。

讲解重点：

> AI 可以接入任意 OpenAI-compatible 模型。当前演示环境如果没有远程密钥，会明确使用本地教学引擎，不会把规则回答伪装成远程模型。会话和消息会持久化。

## 03:00-03:35 考勤与学情

操作：

1. 返回考勤页，点击“立即签到”，输入 `8246`。
2. 展示签到成功和出勤率更新。
3. 进入学情分析，展示近 14 天趋势、课程掌握度、作业表现和出勤构成。
4. 点击“导出 CSV”。

讲解重点：

> 签到码、关闭时间、课程归属和重复签到都由服务端校验。学情数据来自课程、作业、学习记录和考勤，并可导出真实 CSV。

## 03:35-04:20 教师工作台与作业批改

操作：

1. 退出并切换教师身份登录。
2. 展示课程、学生、待批改、平均分和班级风险数据。
3. 进入作业与批改，打开一份学生提交。
4. 填写评分与反馈并保存。

讲解重点：

> 教师只能访问自己创建的课程和提交。评分保存后会生成学生通知，实现反馈闭环。

## 04:20-05:15 教师签到与班级学情

操作：

1. 进入课堂考勤，发起签到，展示签到码。
2. 查看签到名单与出勤率。
3. 进入班级学情，展示成绩分布、优先关注学生和作业有效性。

讲解重点：

> 数据不是为展示生成的假图表，而是根据当前课程名册、作业提交、评分和签到计算。

## 05:15-05:45 通知与移动端

操作：

1. 发布一条课程通知。
2. 切换手机视口，打开移动导航，展示教师工作台。

讲解重点：

> 通知会写入数据库，并为对应范围用户生成站内提醒。移动端保留完整导航和关键数据，不使用不可点击的占位按钮。

## 05:45-06:00 收束

讲解：

> 知澜智慧校园通过真实认证、角色权限、AI 上下文、作业反馈、课堂签到和数据运营，将 AI 融入完整教学闭环。项目已通过 API 回归和浏览器多轮截图验收，可部署到支持 Node 和持久磁盘的云环境。

## 录制检查

- 不展示 `.env`、API Key、终端隐私或真实个人数据。
- 浏览器缩放建议 100%，录制分辨率 1920x1080。
- Toast 出现后停留 1 秒，避免关键操作没有被镜头捕捉。
- 如果现场模型响应较慢，保留等待状态并说明正在调用真实接口。
- 视频发布到 B 站、抖音或快手后，将有效链接填入比赛表单。
