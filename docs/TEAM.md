## 协作原则

- 前端与服务端通过类型化 API 和真实数据库协作，不维护模拟业务数据。
- AI 回答始终标明远程模型或本地教学引擎，远程故障时明确提示回退。
- 所有可见按钮必须连接真实接口、页面导航或本地可验证状态。
- 提交前执行全部自动化测试，并保留关键页面和实时协作截图。
- 数据库、运行日志、API Key 和真实学生信息不进入公开仓库。
